# Linux Fundamentals & Basic Commands Guide

---

## 1. Difference between Shell and Kernel

* **Kernel**: The core component of the operating system that directly manages hardware resources (CPU, memory, disk) and allocates system resources required for software processes to run.
* **Shell**: A command-line interpreter and user interface that sits between the user and the kernel. It receives user commands, translates them for the kernel, and displays the execution results.

---

## 2. Essential Linux Commands

### `pwd` (Print Working Directory)
Displays the absolute path of the current working directory.

### `cd` (Change Directory)
Navigates between directories.
* `/` : Root directory (the starting point of absolute paths)
* `.` : Current directory
* `..` : Parent (upper-level) directory
* `~` : Current user's home directory
* `./`, `../` : Relative path notations based on the current location

### `ls` (List)
Lists files and directories in the current or specified path.
* `-l` : Displays long listing format (permissions, ownership, file size, modification date, etc.)
* `-a` : Lists all files, including hidden files (files starting with `.`)
* `-lh` : Displays file sizes in human-readable formats (e.g., KB, MB, GB)
* `ls /bin` : Lists contents inside a specific directory (e.g., `/bin`)

### `cp` (Copy)
Copies files or directories.
* `cp file1 file2` : Copies `file1` and saves it as `file2`.
* `cp file1 dir1` : Copies `file1` into the `dir1` directory.
* `-r` (or `-R`) : Recursively copies a directory and all of its contents.

### `mv` (Move)
Moves or renames files and directories.
* `mv file1 file2` : Renames `file1` to `file2`.
* `mv file1 dir1` : Moves `file1` into the `dir1` directory.
* `mv file1 file2 dir1` : Moves multiple files (`file1`, `file2`) into `dir1`.
* `mv dir1 dir2` : Renames `dir1` to `dir2` (or moves `dir1` inside `dir2` if `dir2` already exists).

### `rm` (Remove)
Deletes files or directories.
* `rm file1` : Deletes `file1`.
* `-r` : Recursively deletes a directory and all of its contents.

---

## 3. Key Linux Terminal Features

* **`Tab` Key** : Auto-completes command names, file names, and directory paths.
* **Up Arrow (`↑`)** : Scrolls through previously executed command history.
* **`clear`** : Clears the current terminal screen.
* **`help cd` / `man cp`** : Opens help documentations and manuals for commands and options.

---

## 4. Wildcards

Wildcards are used to select multiple files or directories matching specific pattern criteria at once.

* `*` : Matches zero or more characters.
  * Example: `g*` (matches all files starting with `g`)
* `?` : Matches exactly one single character.
  * Example: `data???` (matches `data111`, `data123`, `data595`, etc.)
