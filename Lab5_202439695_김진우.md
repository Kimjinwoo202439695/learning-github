# Linux I/O Redirection, Permissions, and Utilities Guide

---

## 1. I/O Redirection & Pipe

Redirection allows you to redirect the standard input (keyboard) and standard output (screen) of a command to files or other commands.

### Standard Output
* `>` **(Overwrite)**: Redirects command output to a file, overwriting existing content.
  * Example: `ls -lh > file_list.txt` (saves detailed file list to `file_list.txt`)
* `>>` **(Append)**: Appends command output to the end of an existing file (creates a new file if it does not exist).

### Standard Input
* `<` **(Input Redirection)**: Passes file content as input to a command instead of keyboard input.
  * Example: `cat file_list.txt` (displays file contents on the screen)

### Pipeline (`|`)
* Connects the **Output** of the preceding command directly as the **Input** for the next command.
  * Example: `ls -lh | grep "txt"` (filters only lines containing "txt" from the list output)

---

## 2. Terminal Operations & Helpers

* **Backslash (`\`) - Line Continuation**
  * Allows you to split a long command across multiple lines without executing it immediately upon pressing enter.
* **`history`**
  * Displays a chronological list of previously executed terminal commands.

---

## 3. Permissions & Privileges

* **File Permissions**
  * Access rights assigned to **User (Owner)**, **Group**, and **Others** for reading (`r`), writing (`w`), and executing (`x`) files or directories.
* **`chmod` (Change Mode)**
  * Modifies file or directory access permissions.
* **`sudo` (SuperUser Do)**
  * Executes a command with elevated administrator (`root`) privileges temporarily.

---

## 4. Text Editors

Programs used to create and edit files in CLI or GUI environments.

* **Terminal-based Editors (CLI)**
  * `vi` / `vim`: Standard Linux text editor featuring powerful keyboard-driven editing shortcuts.
  * `nano`: User-friendly, simple, and intuitive CLI editor for beginners.
  * `emacs`: Highly extensible and powerful customizable editor.
* **GUI-based Editors**
  * `gedit`: Default graphical text editor for GNOME desktop environments.
  * `kwrite`: Lightweight graphical text editor for KDE desktop environments.

---

## 5. Shell Script

* An executable file containing a series of Linux commands and control structures (if statements, loops) to automate workflow processes (typically uses `.sh` extension).

---

## 6. Network Utilities

* **`wget [URL]`**
  * A non-interactive network downloader used to download files or webpages directly from web servers.
* **`curl [URL]` (Client URL)**
  * A command-line tool for transferring data (uploading and downloading) to or from a server using various protocols (HTTP, HTTPS, FTP, etc.).
